## Why and what changed

The lead author identified a serious misstatement in experiment019: saying John Snow had not used a proximity-based partition erases his real 1855 contribution. Snow's revised map for the parish inquiry added a dotted line delimiting places equally far **by the nearest road** from the Broad Street pump and competitors. This is an early street-network Voronoi catchment, although **not** the full Euclidean 13-pump Voronoi/Delaunay tessellation computed by our interactive library. The earlier version of Snow's map did not contain the revised road-distance boundary. We corrected `article/main.tex`, `site/article.html`, the historical data notes and editorial documentation, citing:

- Snow's 1854/1855 report as reproduced by [UCLA Epidemiology](https://epi-snow.ph.ucla.edu/Stream2_BSPoutbreak_a.html) and the [history of the two versions](https://epi-snow.ph.ucla.edu/Stream2_BSPoutbreak_f.html).
- Shiode, S. (2012). *Revisiting John Snow's map: Network-based spatial demarcation of cholera area*. `https://doi.org/10.1080/13658816.2011.577433`.
- HistData's 13-pump/578-death digitization: `https://friendly.github.io/HistData/reference/Snow.html`.

## Fixed-sample experiment

Run from root:

```bash
python scripts/export_scenes.py
python experiments/experiment020/compare_graph_metrics.py --check --save experiments/experiment020/results.json
python -m unittest discover -s tests -v
python scripts/check_article.py
```

The metrics script uses **only Python standard-library** Dijkstra, reading `site/data/scenes.json` generated by the pinned library. Each edge has weight equal to the Euclidean distance between its two fixed normalized endpoints. For every unordered pair of the 25 vertices, define stretch `d_G(i,j)/||x_i-x_j||`. The mean is over **300 pairs**. Both graphs are connected.

| Quantity | Gabriel | RNG |
| --- | ---: | ---: |
| Vertices | 25 | 25 |
| Edges | 46 | 31 |
| Total edge length (normalized units) | 7.873373853 | 4.791049476 |
| Mean route stretch (300 pairs) | 1.100802912 | 1.271160882 |
| Maximum pair stretch | 1.502664990 | 2.298666402 |
| Connected components | 1 | 1 |

The RNG saves **39.15%** total edge length for these fixed sites, but average detour increases **15.48% relative to Gabriel**. This is a direct geometric tradeoff, not an empirical infrastructure cost estimate or a routing guarantee. Preserved exact values in `results.json`, validated by the script, and a new CI check in `build.yml`.
