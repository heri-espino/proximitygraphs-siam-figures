Who Counts as a Neighbor?

From geographic maps to a Python laboratory of proximity graphs

Heriberto Espino-Montelongo · UDLAP   Héctor Maravillo · UAM, Mexico

Interactive author preview — not published or endorsed by SIAM News. The original software and diagrams are open for inspection.

A set of points contains no instructions about how its members should be connected. A water pump, a pixel, a sensor and a learned embedding each suggest different notions of a neighbor. Proximity graphs turn these decisions into mathematical rules that can be examined, compared and changed.

How Did Proximity Graphs Emerge?

Voronoi regions formalize nearest-site partitions, while Delaunay triangulations connect sites with adjacent regions. The historical Soho cholera map of John Snow provides a compelling setting for these constructions: our modern overlay partitions digitized pump locations, while deaths remain independent observations. Snow did not construct the diagram, and Euclidean distance is not equivalent to walking distance or water use.

Gabriel and Sokal introduced empty-disk adjacency for geographic variation analysis in 1969. Toussaint's 1980 relative neighborhood graph replaced the disk with a lens, while alpha-shapes, β-skeletons and γ-neighborhood graphs later expanded the questions researchers could ask of spatial data. Today these alternative definitions of locality are useful in geometry, spatial planning, image analysis, and computational networks.

How Does a Graph Decide Which Edges Exist?

An empty-region graph joins two sampled points only if their corresponding exclusion region contains no competing sample. For a finite point set P and region K(p,q), the basic criterion is

{p,q} ∈ EK(P) ⇔ K(p,q) ∩ (P ∖ {p,q}) = ∅(1)

Changing the exclusion region changes the graph: the Gabriel criterion uses a disk, the relative neighborhood rule uses a lens, and β-skeletons vary the construction with a parameter. These are useful candidates for spatial-network design, but geometry alone cannot prove that a wireless link is feasible.

A Probabilistic Prediction

Suppose points form a stationary Poisson process with density ρ in d-dimensional space, and the empty-region volume for two sites at separation r is aKrd. Then the absence of other points has probability exp(−ρaKrd). In the idealized model, the mean degree becomes

E[deg] = vd / aK(2)

Here vd is the unit-ball volume. The intensity cancels: the geometric exclusion rule controls mean degree. This is a theoretical baseline, not a claim that every real-world sample follows a Poisson process. The Python package is presently strongest for planar calculations even where the underlying mathematics extends to higher dimensions.

How Can You Use ProximityGraphs?

ProximityGraphs implements classical Voronoi, Delaunay, Gabriel, relative-neighborhood and minimum-spanning graphs, together with alpha constructions, β-skeletons, γ-neighborhoods, stepping-stone graphs and related variants. SetPoints creates structured and stochastic point sets, while Experiment supports seeded comparisons and graph statistics. The original reference diagrams come from the pinned Python package; point edits in the live demonstrations use separate JavaScript geometry.

Install the MIT-licensed library with pip install proximitygraphs, inspect the source code, consult the documentation, or open the complete geometry laboratory. Changing the neighborhood model is not a cosmetic option: it changes the mathematical assumptions behind the network.
