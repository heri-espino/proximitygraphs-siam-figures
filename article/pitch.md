# SIAM News Software and Programming pitch — NOT SENT

**Title:** Who Counts as a Neighbor?  
**Subtitle:** From Geographic Maps to a Python Laboratory of Proximity Graphs  
**Proposed authors:** Heriberto Espino-Montelongo (UDLAP, first author); Héctor Maravillo (UAM Mexico, second author). No other article authors.

Proximity graphs transform scattered spatial observations into networks. Different rules can recover different neighbors, boundaries, paths and local structures. Our article narrates the development from Voronoi/Delaunay through Gabriel graphs, relative-neighborhood graphs, alpha-shapes, beta-skeletons and gamma-neighborhoods, then makes those constructions available through the open-source **ProximityGraphs** Python library.

The proposed online version has **four numbered, fully interactive examples**: historical Soho pump Voronoi partitions (not a model used by Snow), synthetic alpha-shape letterform reconstruction, synthetic beta-skeleton sensor links with explicit empty-lune blockers, and Gabriel-vs-RNG comparison on identical points with optional Poisson/binomial samples. All are accessible on the [online article preview](https://heri-espino.github.io/proximitygraphs-siam-figures/article.html) and have standalone static source figures for PDF/print.

Our editorial reference is SIAM News's [September 28, 2026 VisualPDE Software and Programming feature](https://www.siam.org/publications/siam-news/articles/visualpde-interactive-spatiotemporal-modeling-via-web-browsers-on-any-device/): it includes four captioned interactive animations, equations, headings, applications and links. This is a structural reference, not a claim of approval. SIAM's style guide normally recommends **one to three figures**, so we request permission for four online demonstrations and can reduce the static print selection if necessary. Each iframe is hosted by the authors and might instead be linked externally if SIAM cannot embed it.

The story highlights verified library functions, reproducible experiments, Python-generated reference data, and the separate browser's editable diagrams. It does **not** claim biological-network functionality in this feature, high-dimensional support for all constructors, operational wireless deployment, or causal inference from historical data.

**Editorial status:** Not submitted or accepted. Héctor's approval, artwork/data reproduction rights, and editor permission for four online figures remain outstanding.
