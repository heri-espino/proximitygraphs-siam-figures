## Formats accepted by the venue

[SIAM News submission guidelines](https://www.siam.org/publications/siam-news/about-siam-news/submission-guidelines/) and [two-page style guide](https://www.siam.org/media/miiln0pt/siam-news-info-and-style-guide.pdf) accept a completed **PDF or Word** manuscript. LaTeX source is helpful for mathematical articles, but SIAM News has no mandatory research-journal article class. Markdown is not the listed final submission format.

This repository uses LaTeX from the drafting phase because the article contains mathematical notation and original figures. The PDF is a **reviewable author proof**, not an approved publication or a journal-formatted galley.

## Reproducibility

Run from the root:

    python scripts/check_article.py
    cd article
    pdflatex -interaction=nonstopmode -halt-on-error main.tex
    pdflatex -interaction=nonstopmode -halt-on-error main.tex

The CI [article PDF workflow](../.github/workflows/article-pdf.yml) runs after changes to \`article/main.tex\` on \`main\` (or on manual dispatch), checks the article, compiles it twice, verifies actual embedded PNGs, uploads a proof artifact, and commits the generated PDF to \`article/output/\`.

**Never run \`scripts/render_article.py\` for current manuscript updates.** That historical Markdown converter now outputs a separate \`article/legacy-md-proof.tex\` to prevent overwriting the canonical LaTeX.

## Editorial scope

The current feature tells a scientifically grounded historical story: Voronoi/Delaunay (1908/1930s), Gabriel and Sokal (1969), Toussaint RNG (1980), alpha-shapes (1983), beta-skeleton computational morphology (1985), gamma-neighborhood (1992), stochastic/transport theory, present-day ML and the implemented **ProximityGraphs** library, including Physarum/fungal-inspired graph heuristics. It keeps exactly three attributed figures and ten references.

The geometry illustrations do **not** imply that Snow constructed a Voronoi diagram, that the synthetic sensor graph is a physical network, or that the software implements every high-dimensional theory or biological model exactly.
